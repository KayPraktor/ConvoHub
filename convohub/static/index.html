    تنظیمات ایجنت

      ابزارهای MCP با «همیشه اجازه بده» این‌ها بدون پرسیدن اجرا میشن. با × اجازه‌شون پس گرفته میشه (همون لحظه ذخیره میشه).
        افزونه‌ی مرورگر فقط افزونه‌ای که ID‌ش اینجاست می‌تونه به ConvoHub مکالمه بفرسته. ID رو از صفحه‌ی chrome://extensions بردار، یا وقتی افزونه اولین بار وصل میشه از نوار بالای کتابخونه «قبول» رو بزن.

        کلید OpenRouter

        ConvoHub برای حرف زدن با مدل‌ها از OpenRouter استفاده می‌کنه. اونجا یه حساب بساز، کمی اعتبار بخر و از صفحه‌ی Keys یه کلید بساز (با sk-or- شروع میشه).

        کلید فقط روی همین کامپیوتر و رمزنگاری‌شده با حساب ویندوزت ذخیره میشه؛ توی بکاپ‌ها نمیره و هیچ‌جا کامل نشون داده نمیشه.

        اتصال

        با افزونه، چتی که توی Chrome یا Edge باز کردی (Gemini، ChatGPT، Claude، Grok) با یه کلیک میاد توی کتابخونه و پیام‌های جدیدش خودکار اضافه میشن.

        1. پوشه‌ی افزونه:
        2. توی Chrome بنویس chrome://extensions (توی Edge: edge://extensions) و Enter بزن.
        3. Developer mode (حالت توسعه‌دهنده) رو روشن کن.
        4. Load unpacked رو بزن و همون پوشه‌ی بالا رو انتخاب کن.
        5. یه صفحه‌ی چت (مثلاً یه مکالمه‌ی ChatGPT) رو باز یا refresh کن. اینجا، بالای کتابخونه، نوار «یه افزونه می‌خواد وصل بشه» میاد: قبول رو بزن.
        6. حالا روی صفحه‌ی چت، پایین سمت راست، دکمه‌ی «بفرست به ConvoHub» رو بزن.

        با این‌ها ابزارهای دیگه (Claude Code، Hermes، OpenCode، Cline) هم کتابخونه‌ت رو می‌بینن. مسیرها مخصوص همین کامپیوترن. لازم نیست ConvoHub روشن باشه.
